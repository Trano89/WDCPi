# Sécurité / Security

**Français.** Vous avez trouvé une faille dans WDCPi ? Merci de ne pas la publier dans une issue. Signalez-la en privé :
onglet **Security** de ce dépôt, puis **Report a vulnerability**. Décrivez la version de WDCPi, le problème et comment
le reproduire. Nous répondons dès que possible et publions une version corrigée, signée, que les consoles installent
d'elles-mêmes.

**English.** Found a vulnerability in WDCPi? Please do not post it in an issue. Report it privately through this
repository's **Security** tab, then **Report a vulnerability**. Include the WDCPi version, the problem and how to
reproduce it. We answer as soon as possible and publish a fixed, signed release, which installed consoles install on
their own.

Les versions publiées sont signées (OpenSSH, espace de noms `wdcpi-release`). Empreintes des clés de publication /
